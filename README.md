# 🛒 E-Commerce Checkout Flow Redesign

A UI/UX case study focused on redesigning the checkout flow of an e-commerce website to create a smoother, faster, and more user-friendly purchasing experience.


## 👩‍💻 Internship Details

- **Company:** SkillCraft Technology
- **Domain:** UI/UX Design
- **Intern ID:** SCT/JUL26/0246

## 📌 Project Name
**E-Commerce Checkout Flow Redesign**

## 📝 Project Description

Redesigned the checkout flow of an e-commerce website by simplifying the user journey, improving navigation, reducing checkout friction, and creating a clean, modern interface using Figma.

## 🛠️ Tools Used

- Figma
- Iconify
